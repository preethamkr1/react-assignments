# React Assignments — Completed

This repository contains two independent React + Vite applications.

## 1. Photo Gallery
```bash
cd photo-gallery
npm install
npm run dev
```
Features: Picsum paginated feed, one-column gallery, infinite scroll, author and image display, per-image like counter, loading/error states, retry, and image fallback.

## 2. Chat App
```bash
cd chat-app
npm install
npm run dev
```
Features: send messages, randomly assigned usernames, per-message likes, Enter-to-send, emoji picker, and @mentions suggestions.

Each app runs independently. Node.js 18+ is recommended.
